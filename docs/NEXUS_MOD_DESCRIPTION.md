## 8. Full Description - Markdown (Alternative si éditeur WYSIWYG)

Complete French fan-translation (VOSTFR) adapted specifically for the GOG DRM-free edition of the game, based on the acclaimed community translation by **Byce61** and the **Yakuza RGG France** team.

---

### What It Does
Adapts the complete French subtitle, gameplay, combat, and menu translation to the GOG release without distributing copyrighted executable files. It provides all translated game archives, calibrated property tables, and an automated, 1-click patcher that safely configures your clean GOG executable for Western ANSI character encoding and French text rendering.

---

### Key Features
* **Full Story & Substories in French**: 100% of all main story cutscenes, dialogue, substories, and pager messages translated.
* **Combat & Heat Actions**: 100% of ability trees, battle styles (Brawler, Rush, Beast, Dragon / Thug, Slugger, Breaker, Mad Dog), all Heat Actions (*Essence of...*), and battle ranking evaluations.
* **Business & Management**: 100% localized Real Estate Royale (all 33 employees & Five Billionaires) and Cabaret Club Czar (all 30 hostesses & rival clubs).
* **French UI, Shops & Menus**: Inventory, Equipment, CP Virtue Shrines, Pager messages, Controller overlays, System Settings, Save/Load, and all 35 stores (558 translated item descriptions).
* **Native Font Kerning**: Calibrated symmetrical letter metrics ([0.4, 0.4]) preserving clean character spacing without overlapping or crushed letters ('i', 'l', etc.).
* **1-Click Safe Patcher**: Automated script that backs up your original `Yakuza0.exe` to `Yakuza0.exe.bak` before applying binary patches.
* **DRM-Free Integrity**: Designed exclusively for the GOG edition (Build 3642285 / v1.015a). 131/131 PAR archives audited and validated (0 crashes, 0 memory overflows).
* **Linux & Steam Deck Ready**: Includes a native shell script (`patch_gog.sh`) for Wine, Proton, Heroic, and Lutris users.

---

### Scope & Preserved Terms (By Design)
To ensure lore authenticity, respect official licensing, and prevent engine memory faults, a small subset of elements is intentionally preserved in its original format:
* **Sega Arcade Classics**: Worldwide official titles and arcade cabinets (*Out Run*, *Space Harrier*, *Super Hang-On*, *Fantasy Zone*, *UFO Catcher*) keep their licensed commercial names.
* **Licensed Music Tracks**: Licensed Disco songs (*I Wanna Take You Home*, *Friday Night*, etc.) keep their original titles.
* **Traditional Games**: Official Japanese/international rules, calls, and Yaku for Mahjong (*Riichi, Ippatsu, Ron, Tsumo, Dora*) and Shogi.
* **Real-Life AV Idols**: Authentic Japanese stage names on collectible cards.
* **Internal Engine Keys**: Low-level engine tags and animation identifiers that would trigger memory faults if renamed.

---

### Installation (Windows)
1. Extract all contents from the release archive directly into your game root directory (where `Yakuza0.exe` is located).
2. Right-click **`patch_fr.bat`** and select **Run as administrator**.
3. A clean backup `Yakuza0.exe.bak` is created automatically, and the game is patched in seconds.
4. Launch the game normally via GOG Galaxy or directly through `Yakuza0.exe`.

### Installation (Steam Deck / Linux)
1. Copy the extracted files into your game folder inside your Wine / Proton / Heroic prefix.
2. Open a terminal in the game folder and run:
   ```bash
   chmod +x patch_gog.sh
   ./patch_gog.sh
   ```
3. Launch the game through your launcher.

---

### Compatibility
* **Game Version**: Compatible with **GOG Edition v1.015a (Build 3642285)**.
* **Save Files**: 100% compatible with existing saves.
* **Steam Version**: Do not install this mod on Steam; use the original Steam patch release by Yakuza RGG France instead.
