## 8. Full Description - Markdown (Alternative si éditeur WYSIWYG)

Complete French fan-translation (VOSTFR) adapted specifically for the GOG DRM-free edition of the game, based on the acclaimed community translation by **Byce61** and the **Yakuza RGG France** team.

---

### What It Does
Adapts the complete French subtitle and menu translation to the GOG release without distributing copyrighted executable files. It provides all translated game archives and an automated, 1-click patcher that safely configures your clean GOG executable for Western ANSI character encoding and French text rendering.

---

### Key Features
* **Full Story & Substories in French**: 100% of all main story cutscenes, dialogue, substories, and pager messages translated.
* **French UI & Menus**: Inventory, Equipment, Abilities, Pager, Settings, and chapter titles translated into French.
* **Native Font Kerning**: Preserves clean native character spacing without overlapping or crushed letters ('i', 'l', etc.).
* **1-Click Safe Patcher**: Automated script that backs up your original `Yakuza0.exe` to `Yakuza0.exe.bak` before applying binary patches.
* **DRM-Free Integrity**: Designed exclusively for the GOG edition (Build 3642285 / v1.015a). Never crashes due to missing Steamworks libraries.
* **Linux & Steam Deck Ready**: Includes a native shell script (`patch_gog.sh`) for Wine, Proton, Heroic, and Lutris users.

---

### Installation (Windows)
1. Navigate to your game installation directory (e.g. `C:\GOG Games\Yakuza 0\`).
2. Extract all contents from the release archive directly into your game root directory (where `Yakuza0.exe` is located).
3. Confirm replacing/overwriting existing files when prompted.
4. Double-click **`patch_gog.bat`** (or run `python patch_gog.py Yakuza0.exe` in a terminal).
   * A clean backup `Yakuza0.exe.bak` will be created automatically.
   * Font tables, single-byte rendering routines, and menu strings will be patched in a few seconds.
5. Launch the game normally via GOG Galaxy or directly through `Yakuza0.exe`.

### Installation (Steam Deck / Linux)
1. Copy the extracted files into your game folder inside your Wine / Proton / Heroic prefix.
2. Open a terminal in the game folder and run:
   ```bash
   chmod +x patch_gog.sh
   ./patch_gog.sh
   ```
3. Launch the game through your launcher.

---

### Compatibility
* **Game Version**: Compatible with **GOG Edition v1.015a (Build 3642285)**.
* **Save Files**: Compatible with existing saves.
* **Steam Version**: Do not install this mod on Steam; use the original Steam patch release by Yakuza RGG France instead.

---

### Known Issues
* **Arcade Textures**: 5 to 6 dynamic in-game mini-game arcade banners (*"Ability Acquired"*, *"Congratulations!"* on UFO Catchers) remain in English as they are hardcoded 2D graphic textures rather than text strings.
* **Pause Menu Stats**: Certain secondary stat labels (*Battle, Completion, Substories*) were kept in English in accordance with the original VOSTFR translation design.
* **Uninstallation**: To restore the clean vanilla executable, simply delete `Yakuza0.exe` and rename `Yakuza0.exe.bak` back to `Yakuza0.exe`.
